# {{< icon "fa fa-cloud" >}} 123Pan

Paths are specified as `remote:path`

The initial setup for 123Pan involves logging in with your 123Pan account.
Unlike the [123 Open](/123open/) backend which uses the official developer API,
this backend uses the reverse-engineered Web/Browser API.

## Configuration

Here is an example of how to make a remote called `remote`. First run:

    rclone config

This will guide you through an interactive setup process:

```
No storage type configured.
Choose a number from below, or type in your own value
XX / 123Pan (Web API)
   \ (123pan)
Storage> 123pan

123 Pan login username or email.
Enter a value.
username> your_username

123 Pan login password.
Enter a value.
password> your_password
```

### Standard options

Here are the Standard options specific to 123pan (123Pan Web API).

#### --123pan-username

123 Pan login username or email.

- Config:      username
- Env Var:     RCLONE_123PAN_USERNAME
- Type:        string
- Required:    true

#### --123pan-password

123 Pan login password.

- Config:      password
- Env Var:     RCLONE_123PAN_PASSWORD
- Type:        string
- Required:    true

### Advanced options

Here are the Advanced options specific to 123pan (123Pan Web API).

#### --123pan-upload-thread

Number of concurrent threads for chunked uploads.

- Config:      upload_thread
- Env Var:     RCLONE_123PAN_UPLOAD_THREAD
- Type:        int
- Default:     4

#### --123pan-platform

Platform identifier sent in API headers.

- Config:      platform
- Env Var:     RCLONE_123PAN_PLATFORM
- Type:        string
- Default:     "web"

#### --123pan-encoding

The encoding for the backend.

See the [encoding section in the overview](/overview/#encoding) for more info.

- Config:      encoding
- Env Var:     RCLONE_123PAN_ENCODING
- Type:        encoding

## Limitations

123Pan does not support modification times. The modification time
shown will be the time the file was last modified on the server.

123Pan cannot store empty (0 byte) files. Attempting to upload an empty
file will result in an error.

123Pan does not support uploading files of unknown size (streaming).
The file size must be known before uploading.

123Pan has eventual consistency, so changes may not appear immediately.

123Pan supports instant upload (秒传). If you upload a file that already exists
on 123Pan's servers (based on MD5 hash), the upload will complete instantly
without transferring data.
